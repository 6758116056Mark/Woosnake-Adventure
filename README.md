# Avatar Snake: The Dude Chase 🐍⚡

An arcade snake game where Avatar Dude is the laser-eyed snake hunting Polo Apple Dude across the spiritual grid. Built with React 19, TypeScript, Vite, Tailwind CSS, and HTML5 Canvas.

![Avatar Snake](public/assets/aistudio/image_67593ebe.png) vs ![Polo Dude](public/assets/aistudio/image_6f2c4f24.png)

## Features
- **Avatar Snake**: Laser-beam eye flares, forehead arrow glow, slithering directional tilt, and chomping animations.
- **Apple Dude**: Cute fruit halo, apple twig stem, glossy green leaf, and humorous reactive quips.
- **Powerup Apples**:
  - 🍏 **Normal Dude Apple**: +100 pts.
  - 🌟 **Golden Dude Apple**: Triggers 10s of full Avatar State with tail slicing and 2x combo multipliers!
  - 🌶️ **Spicy Dude Apple**: Fiery speed boost trail.
  - ❄️ **Zen Focus Apple**: Slow-motion precision navigation.
- **60fps Game Feel**: Screen shake, hitstop freeze-frames, Web Audio procedural synth sound effects and ambient soundtrack.
- **Responsive Controls**: Desktop `WASD`/Arrow keys + `Space` boost, and mobile on-screen D-Pad.
- **Customization**: Difficulty options, Wall Wrap vs Deadly Walls modes, SFX & Synth Music toggles.

## How to Run Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/avatar-snake-game.git
   cd avatar-snake-game
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

4. **Build for production**:
   ```bash
   npm run build
   ```

## Controls
- **Move**: `W`, `A`, `S`, `D` or `Arrow Keys`
- **Boost / Dash**: `Space` or `Shift`
- **Pause / Resume**: `Esc`
- **Mobile**: Touch the on-screen D-pad and Boost button
